# DressSharp for Rider

Format C# with your repository's DressSharp rules on save, as you type, or with **Code | Format with DressSharp**. Requires Rider 2025.2 or later and the .NET 10 SDK or later.

## Install

1. Download `DressSharpRider-<version>.zip` from the **Assets** of a [DressSharp GitHub release](https://github.com/soxtoby/DressSharp/releases).
2. In Rider, open **Settings | Plugins**, click the gear icon, and choose **Install Plugin from Disk**.
3. Select the ZIP without unpacking it, then restart Rider if prompted.

See the [Rider plugin guide](https://soxtoby.github.io/DressSharp/rider/) for repository setup, formatting options, and settings.
